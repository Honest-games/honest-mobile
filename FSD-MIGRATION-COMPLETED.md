## Преимущества новой архитектуры

1. **Четкая структура** - каждый компонент на своем месте
2. **Масштабируемость** - легко добавлять новые фичи
3. **Переиспользование** - компоненты и хуки переиспользуются
4. **Единообразие** - вся работа с API через единую архитектуру
5. **Типобезопасность** - все типы приведены в соответствие
6. **Читаемость** - понятная структура для новых разработчиков

## Для разработчиков

### Правила разработки:
1. Новые компоненты добавляйте в соответствующие FSD слои
2. Следуйте правилам импортов (снизу вверх по слоям)
3. API эндпоинты добавляйте через `api.injectEndpoints`
4. Изучите `docs-fsd.md` для понимания архитектуры

### Быстрые команды:
```bash
# Проверка типов
npx tsc --noEmit

# Проверка структуры
find . -name "*.ts*" | grep -E "(components|UI)/" # должно быть пусто
```
